# Superstore - Sales and Profitability Analytics Dashboard

I built a comprehensive Sales and Profitability Analytics solution using the classic Superstore dataset, designing both an interactive executive dashboard in Power BI and a pixel-perfect operational report in Report Builder.

## Key Technical Highlights

- **Data modeling & ETL:** Structured a clean star schema with dedicated fact and dimension tables, eliminating circular dependencies and optimizing query performance.
- **Advanced DAX layer:** Implemented complex measures including dynamic ABC customer segmentation using RANKX and ALLSELECTED, rolling Year-to-Date (YTD) calculations, and Year-over-Year (YoY) growth tracking.
- **Executive UI/UX & reporting:** Designed a professional custom-themed dashboard featuring regional geospatial maps, decomposition trees, hover tooltips, and a structured, export-ready paginated report.

This project sharpened my ability to translate raw transactional data into actionable enterprise insights across multiple reporting layers.
