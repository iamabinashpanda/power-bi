# Sales and Profitability Dashboard

An iterative Sales and Profitability Dashboard built in Power BI! 📊

Following my previous work, this project focused heavily on operational metrics, UI/UX enhancement, and finding the cleanest way to present financial data to stakeholders to help them in decision making. I improvise the layouts and colour palettes to see how visual hierarchy impacts data readability.

## Key Technical & Design Highlights

- **Financial metric architecture:** Built robust measures for Total Amount, Total Cost, Total Profit, and Profit Margin (52.91%) to give an immediate executive-level summary.
- **Geospatial & category breakdown:** Integrated regional performance charts across countries (India, UK, USA, Canada, Australia) alongside stacked category comparisons.
- **UI/UX iteration & readability:** Tested and refined multiple thematic designs—moving from a high-contrast dark executive theme to a bright, structured layout—to optimize how users consume daily trends, team breakdowns, and seasonal performance curves.
- **Advanced visuals:** Included dual-axis trend analysis, daily amount tracking with goal benchmarks, and custom decomposition/flow charts.

Iterating on dashboard designs taught me a lot about how spacing, contrast, and color choices directly influence data storytelling and user experience.

## Design Note

As an added design challenge, I adapted the layout to handle different currency formats (USD vs. INR) and explored multiple color palettes to see how regional branding and layout shifts impact data readability.
