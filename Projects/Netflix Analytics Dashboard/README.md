# Netflix Analytics Dashboard

A custom-themed Netflix Analytics Dashboard built in Power BI!

## Key Technical & Design Highlights

- **Custom theming:** Designed a sleek dark-mode layout utilizing high-contrast styling paired with a signature streaming aesthetic.
- **Core KPI cards:** Aggregated high-level metrics including total runtime in hours (7.513K), total movies vs. TV shows split, and average IMDB ratings (5.94).
- **Advanced visuals:** Integrated a geographical subscriber distribution map, a stacked bar chart analyzing the top genres by content type, and an area chart displaying content growth volume by year from 2000 onward.
- **Interactive filtering:** Configured seamless cross-filtering by title, genre, and release years to make deep-dive exploratory data analysis smooth and intuitive.

## Project Note

This project is purely an independent, educational data visualization exercise utilizing historical public domain/mock data from the 2000–2020 era. It is not affiliated with, endorsed by, or connected to Netflix, Inc., and is created solely for portfolio and skill-building purposes.

This project was a fantastic exercise in translating strict design guidelines into a functional, data-dense reporting environment.
