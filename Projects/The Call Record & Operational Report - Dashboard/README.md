# The Call Record & Operational Report - Dashboard

The Call Record & Operational Report - Dashboard built in Power BI!

As public service sectors look to streamline resolution times and optimize agency workflows, data-driven visibility becomes critical. I designed this multi-page executive reporting suite to help stakeholders track service efficiency, spatial demand, and queue performance.

## Key Features & Technical Highlights

- **Multi-page architecture:** Structured across a Home Summary, Executive Overview, Operational Performance Hub, and Geospatial Analysis map.
- **Advanced DAX modeling:** Engineered custom measures for Year-over-Year (YoY) variance, monthly averages, MTTR (Mean Time to Resolution), and dynamic rolling date slices.
- **Interactive UX & custom tooltips:** Built dynamic report-page tooltips allowing users to inspect neighborhood-level performance metrics on hover without cluttering the main canvas.
- **Granular service flow:** Implemented decomposition trees, matrix distribution grids, and time-of-day binning to isolate operational bottlenecks.

## Tech Stack

Power BI Desktop, DAX, Advanced Data Modeling, UI/UX Dashboard Design Principles.
